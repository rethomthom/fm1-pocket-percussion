# FM1 Pocket Percussion

A self-contained, playable FM percussion instrument for iPhone Safari. It uses Web Audio synthesis—no samples, libraries, or build step.

The app includes 12 touch pads: Low Tom, Deep Tom, Mid Tom, High Tom, Conga, Block, Clave, Noise Hit, Zap, Metal Perc, FM Bell, and Weird Perc.

Each voice has Pitch, Pitch Sweep, Sweep Decay, Amp Decay, FM Ratio, FM Amount, Noise, Filter, Resonance, Drive, and Level controls. Tap a pad to play and select it. Pointer pressure is used as velocity when Safari exposes it. Save Patch and Save Kit store edits in localStorage on the device.

## Enable GitHub Pages

1. Open Settings then Pages in this repository.
2. Under Build and deployment, choose Deploy from a branch.
3. Select the main branch and the root folder, then click Save.
4. Open the generated Pages URL in Safari on iPhone and tap a pad to start Web Audio.
